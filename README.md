# GM Admin Helper 4.0

Плавающая админ-панель поверх игры + клавиатура GM Admin, которая вписывает команды прямо в чат.

## Сборка через GitHub (без Android Studio)
1. Создай на github.com пустой репозиторий (можно приватный).
2. Залей в него все файлы из архива (Add file → Upload files; папку `.github` тоже, она скрытая).
3. Вкладка **Actions** → **Build APK** → **Run workflow** (или просто сделай коммит).
4. Через 5–10 минут открой завершённый запуск → внизу **Artifacts → GM-Admin-Helper-apk** → скачай, распакуй, поставь `app-debug.apk`.

Android SDK берётся готовый с раннера GitHub (шаг `setup-android` убран — он падал на «Failed to find package 'tools'»).

## Настройка на телефоне (по порядку кнопок в приложении)
1. «Поверх других приложений» → разрешить. 2. Включить клавиатуру GM Admin. 3. Выбрать её в чате игры.
4. **Служба доступности «GM Admin — тапы»** → включить (нужна только для авто-открытия чата, ничего не читает).
5. «Запустить панель 🛡» и «Ловец репортов и весь чат» (запись экрана).
6. Открой игру → панель 🛡 → ⚙ Настройки → «Показать кнопку чата и поле»: тапни кнопку чата, потом поле ввода. Для портрета и альбома настраивается отдельно.

## Что внутри панели
- **Главная**: 📨 репорты · 📋 формы из админ-чата (✓ Принять / ✕ Отказать с причиной) · 💬 весь чат (лог, фильтры, поиск).
- Формы = команды /jail /sp /offjail /mute … из админ-чата. «Принять» вписывает и отправляет команду, «Отказать» пишет отказ в /a.
- Счётчики сверху: Репорты, Наказания, ФВ — растут сами, ФВ (и любой другой) можно поправить кнопками − / +.
- Чат в игре закрывается после отправки — приложение само тапнет кнопку чата и поле ввода, потом впишет команду.
- Поворот экрана: панель, клавиатура и захват экрана подстраиваются сами. Кнопка ⇄ в шапке панели переносит её на другую сторону.
