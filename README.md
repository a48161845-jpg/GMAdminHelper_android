# GM Admin Helper 5.8.0

Помощник администратора: клавиатура GM (репорты, команды, правила, журнал учёта), плавающий значок и ловец репортов.

## Сборка и обновление
Push в GitHub → вкладка **Actions** → артефакт **GMAdminHelper** (APK).
APK подписан постоянным ключом `app/gm.jks`, поэтому новая версия ставится **поверх** старой — удалять приложение не нужно.
(Один раз, при переходе со старой версии 3.x, удалить её всё же придётся: у неё был другой ключ подписи.)

## Что внутри
- `app/src/main/assets/panel.html` — клавиатура. `app.html` — экран приложения. `core.js` — общие данные и логика.
- Права: «Поверх других приложений», уведомления, запись экрана (по запросу). Интернета и доступа к статистике приложений нет.

## Что нового в 5.8.0
- **Статистика**: новая вкладка — день (с 00:00), неделя (с понедельника), месяц (с 1 числа); листание в прошлые периоды, сравнение с прошлым, график, среднее в день, самый активный день/час, время работы, наказания по командам и частые причины, копирование отчёта. На главной неделя тоже считается с понедельника.
- **Инструкция**: «Главная» → «Инструкция». Обучение с нуля (12 глав с отметками «пройдено») и подробная справка по использованию (11 глав), поиск. Тот же текст — в INSTRUCTION.md.
- **Пустое приложение**: удалены все встроенные правила, наказания, команды, ответы и кнопки («стандартные наборы» тоже). Уровни команд берутся только из раздела «Команды». Для данных прошлых версий — предложение очистить на главной и «Очистка» в настройках.
- **Настройки**: поиск по всем настройкам, сброс каждого раздела, живой предпросмотр окон, закреплённая панель разделов, «Сохранено ✓».
- Журнал хранит до 20 000 записей, время работы — 66 дней (для месячной статистики).

## Что нового в 5.7.2
- **Зависания клавиатуры**: убраны все синхронные чтения текста поля игры (они блокировали клавиатуру до 2 секунд, если игра занята): стирание, очистка, автоподстановка «/a», ожидание между командами. Данные панели перечитываются только если изменились, журнал — только если изменился.
- **«/sp» после слежки**: команда слежки теперь всегда уходит первой в цепочке, а не вторым пунктом после ответа; ожидание между командами — без чтения поля, команда не теряется, если чат закрылся, и допечатывается при следующем открытии.
- **Ловля**: цифры, прочитанные буквами (O/l/I/S/B/Z) в ID и номере репорта, исправляются; ник с пробелом или точкой вместо «_» собирается в Имя_Фамилия; запятая вместо двоеточия; плохо прочитанные строки (низкая уверенность) перечитываются на следующих кадрах (до двух повторов); слишком узкие полосы не читаются; при сниженном качестве тонкий текст утолщается перед распознаванием.

## Что нового в 5.7.1
- **Повторы репортов**: сравнение нечёткое — тот же ник/ID (с поправкой на ошибки распознавания) + тот же номер репорта или похожий текст не создают новый репорт; ник, уже встречавшийся с тем же ID, сохраняет прежнее написание.
- **Ложные срабатывания**: уверенность распознавания (низкая — отбрасывается), мусорный текст (много странных знаков, нет букв, повторы одной буквы), более строгий ник/ID; строки, только заезжающие в область чтения, не читаются, пока не войдут целиком.
- **Скорость, когда чат летит**: полосы строк распознаются как отдельные задания сразу, не дожидаясь конца предыдущего кадра, и в два потока (настройка «Потоки распознавания»); результаты разбираются строго по порядку, переносы склеиваются верно. Проверка экрана — раз в 100 мс, английский проход только когда нужен.

  - Данные: сброс настроек.

## Что нового в 5.6.2
- **Ложные срабатывания**: строка без хвоста репорта принимается, только если у неё есть след хвоста (скобка в конце), ник вида Имя_Фамилия и правдоподобный ID; перенос на вторую строку ждёт дольше — обрезанные репорты не создаются.
- **Окна репорта и слежки** компактнее: уже (320 dp), без пустых ячеек (неполный ряд кнопок делится поровну), текст репорта в 2 строки; копирование ников/ID спрятано — нажми на имя в шапке («⧉»).

## Что нового в 5.6.1
- **Цепочки команд** («ответ» + «/sp» и т. п.): команда больше не теряется, если поле чата в этот момент закрыто — очередь ждёт; следующая команда пишется, когда игра очистила поле после отправки (иначе очищается само), а не по слепому таймеру. В режиме «/a» автоподстановка не мешает цепочке.

## Что нового в 5.6
- **Ловец**: «тёплые» (оранжевые) строки с нормальным ником и ID принимаются, даже если хвост «[К-во репорта: N]» распознан плохо; белый текст — только с хвостом. До 8 строк за кадр, дольше окно распознавания — пропусков меньше.
- **Окно репорта**: убрана кнопка «Без ответа»; «Ответить ▸» — первая кнопка общей сетки (одна строка меньше); ✕ в шапке закрывает репорт без ответа; убрана лишняя строка «нарушитель».
- **Окно слежки**: «Ответить ▸» есть всегда; если автор репорта неизвестен — ID игрока вписывается прямо в окне ответа.
- **Ответы**: без категорий — один список.
- **Команды (клавиатура)**: под названием снова подпись самой команды.
- **Клавиатура**: кнопка «/a» в шапке — писать сразу в админ-чат: в начало сообщения сама встаёт команда (настраивается), после отправки — снова.

## Что нового в 5.5
- **Ловец**: частота проверки экрана убрана из настроек и зафиксирована на максимуме; каждая строка разбирается сразу после чтения, перенесённые репорты склеиваются и между кадрами. «Только полные репорты» включено по умолчанию + проверка ника/ID — лишнее не ловится. Меньше нагрузки: буферы кадра переиспользуются.
- **Окно репорта**: компактное; после ответа пропадает (дальше — следующий репорт). Кнопка «Ответить ▸» открывает окно со всеми ответами в 2 колонки (прокрутка вниз) и полем «свой ответ». В веере значка появилась кнопка «Репорты N».
- **Клавиатура**: разделы «Репорты», «Команды», «Наказание», «Правила» стали компактнее; команды — фильтр по уровню и 3 колонки; наказание — причина → срок → «Выдать». Набор букв не пересобирается при Shift, реже опрос, стирание через настоящий Delete.
- **Формы админов**: принимаются только для команд, которые есть в разделе «Команды» приложения (и по уровню). Остальные игнорируются.
- **Редизайн приложения**: новая палитра, плавающая навигация с иконками, мягкие карточки, индикатор готовности на главной.
- **Ловец из веера**: кнопка «Ловец» полностью включает/выключает ловлю репортов и запись экрана.
- **Окна слежки и репортов** не занимают весь экран: потолок по высоте с прокруткой, в ландшафте шире и больше кнопок в ряду.
- **Автозапись**: если в репорте есть чужой ID и термин из правил (ДМ, ЗЗ, ТП…), то при нажатии «Слежка» запись экрана включается сама и сохраняется при выходе из слежки (настройка «Автозапись при слежке»).
- **Правила**: пункт без номера — термин; у любого пункта/термина может быть несколько наказаний сразу (jail + warn…), в выдаче они уходят вместе. В списке пунктов: «ДМ | jail 30-60 | + warn».
- **Чистая установка**: правил, пунктов, команд, ответов и кнопок окон нет — всё добавляется самим в приложении.
- **Лаги**: разбор кадров ловца вынесен с главного потока в фон, чтение пикселей строками (в разы быстрее), проверка экрана раз в 140 мс, качество картинки по умолчанию «Среднее».
- **Поля ID/ник**: после очистки ID автора больше не подставляется обратно; вставка «Ник[ID]» превращается в ID.

## Что нового в 5.4

- Меньше мусора: режим «Только полные репорты» (по умолчанию), переключатель «Формы админов», «Один репорт за раз» и пауза после пойманного репорта. Расположение значка и окон задаётся руками: Настройки → «Указать на экране» (перетаскиваешь макеты пальцем).
- Убрано всплывающее уведомление о репорте (остались вибрация и значок). Окна репорта и слежки двигаются за шапку и запоминают место; в них есть ряд «Копировать» (ник/ID автора, ID и ник нарушителя).
- **Репорты не теряются и не повторяются**: длинные (перенесённые на несколько строк) репорты склеиваются, даже если прочитались в разных кадрах; повторы отсекаются по игроку, номеру и тексту.
- **Окно репорта**: не пропадает после ответа (закрывается «Готово ›»), поле «Свой ответ игроку», кнопки помечаются ✓.
- **«На помощь»** шлёт в админ-чат `Ник[ID] нужна помощь: суть`, а игроку — «ваш вопрос передан, ожидайте» (шаг `@ans` в настройке кнопки; шаблон — в настройках кнопок).
- **Слежка**: поле быстрого ответа игроку.
- **Клавиатура**: ✕ у цели работает, поля ID/ников шире, есть «Вст» (вставить из буфера), обновлён вид репорта, выдачи наказания и журнала.
- **Приложение**: главная со статусом, статистикой и подсказками; списки команд и правил сжаты (касание раскрывает действия); удаление — одним касанием с «Отменить».

## Что нового в 5.3
- Убраны Kill List и журнал чата (вкладки «Чат» и «Kill List» в журнале, чтение ленты убийств, настройки к ним). Остался журнал учёта: репорты, наказания, ФВ.
- Ловец занимается только двумя вещами: репорты и формы админ-чата. Каждый кадр читаются лишь оранжевые строки области, поэтому новый репорт или форма появляются в окне почти сразу. Раз в несколько секунд (Настройки → «Страховочное чтение») читаются и светлые строки — на случай другого цвета.
- Карточка «Репорт не разобран» убрана: показываются только распознанные репорты и формы.
- **Область чтения выбирается на экране**: Настройки → «Указать на экране» (или кнопка «Область чтения» в веере значка). Поверх игры появляется рамка: углы и края — менять размер, середина — двигать, пустое место — нарисовать новую. Сохраняется сразу, без перезапуска ловца. Область входит в резервную копию.
- Экран настроек переделан: карточки «Профиль», «Ловец репортов», «Отправка и ответы», «Клавиатура GM», «Резервная копия», «О приложении»; переключатели вместо флажков, быстрые варианты вместо ввода миллисекунд, схема экрана с областью чтения, редкие настройки свёрнуты. Убраны неработавшие пункты («Инвертировать», «Чёрно-белая обработка», «Лёгкий режим»).

## Что нового в 5.1
- Приложение по умолчанию пустое (правила, команды, ответы, тексты автоответов). Готовый набор — Настройки → «Загрузить стандартный набор».
- Кнопки всплывающих окон репорта и слежки настраиваются: Команды → «Кнопки окон». Кнопка = название + цепочка действий (`@ans:sp`, `/sp {id}`, `/flip {id}`, `@help`, `@spoff` …).
- Из окна слежки можно отвечать автору репорта быстрыми ответами, не открывая клавиатуру.
- Резервная копия одним файлом (с журналом): сохранить / загрузить, автокопия раз в N часов в выбранную папку.
- Темы оформления (красная, сиреневая и др.).
- Формы из админ-чата, на которые не хватает уровня, больше не показываются.
- Журнал: у репортов и наказаний нет «минуса», убран комментарий ФВ внизу.
- Чат: копирование ника / ID / строки; очистка от времени и интерфейса игры при распознавании.
