# GM Admin Helper 5.3

Помощник администратора: клавиатура GM (репорты, команды, правила, журнал учёта), плавающий значок и ловец репортов.

## Сборка и обновление
Push в GitHub → вкладка **Actions** → артефакт **GMAdminHelper** (APK).
APK подписан постоянным ключом `app/gm.jks`, поэтому новая версия ставится **поверх** старой — удалять приложение не нужно.
(Один раз, при переходе со старой версии 3.x, удалить её всё же придётся: у неё был другой ключ подписи.)

## Что внутри
- `app/src/main/assets/panel.html` — клавиатура. `app.html` — экран приложения. `core.js` — общие данные и логика.
- Права: «Поверх других приложений», уведомления, запись экрана (по запросу). Интернета и доступа к статистике приложений нет.

## Что нового в 5.4

- Меньше мусора: режим «Только полные репорты» (по умолчанию), переключатель «Формы админов», «Один репорт за раз» и пауза после пойманного репорта. Расположение значка и окон задаётся руками: Настройки → «Указать на экране» (перетаскиваешь макеты пальцем).
- Убрано всплывающее уведомление о репорте (остались вибрация и значок). Окна репорта и слежки двигаются за шапку и запоминают место; в них есть ряд «Копировать» (ник/ID автора, ID и ник нарушителя).
- **Репорты не теряются и не повторяются**: длинные (перенесённые на несколько строк) репорты склеиваются, даже если прочитались в разных кадрах; повторы отсекаются по игроку, номеру и тексту.
- **Окно репорта**: не пропадает после ответа (закрывается «Готово ›»), поле «Свой ответ игроку», кнопки помечаются ✓.
- **«На помощь»** шлёт в админ-чат `Ник[ID] нужна помощь: суть`, а игроку — «ваш вопрос передан, ожидайте» (шаг `@ans` в настройке кнопки; шаблон — в настройках кнопок).
- **Слежка**: поле быстрого ответа игроку.
- **Клавиатура**: ✕ у цели работает, поля ID/ников шире, есть «Вст» (вставить из буфера), обновлён вид репорта, выдачи наказания и журнала.
- **Приложение**: главная со статусом, статистикой и подсказками; списки команд и правил сжаты (касание раскрывает действия); удаление — одним касанием с «Отменить».

## Что нового в 5.3
- Убраны Kill List и журнал чата (вкладки «Чат» и «Kill List» в журнале, чтение ленты убийств, настройки к ним). Остался журнал учёта: репорты, наказания, ФВ.
- Ловец занимается только двумя вещами: репорты и формы админ-чата. Каждый кадр читаются лишь оранжевые строки области, поэтому новый репорт или форма появляются в окне почти сразу. Раз в несколько секунд (Настройки → «Страховочное чтение») читаются и светлые строки — на случай другого цвета.
- Карточка «Репорт не разобран» убрана: показываются только распознанные репорты и формы.
- **Область чтения выбирается на экране**: Настройки → «Указать на экране» (или кнопка «Область чтения» в веере значка). Поверх игры появляется рамка: углы и края — менять размер, середина — двигать, пустое место — нарисовать новую. Сохраняется сразу, без перезапуска ловца. Область входит в резервную копию.
- Экран настроек переделан: карточки «Профиль», «Ловец репортов», «Отправка и ответы», «Клавиатура GM», «Резервная копия», «О приложении»; переключатели вместо флажков, быстрые варианты вместо ввода миллисекунд, схема экрана с областью чтения, редкие настройки свёрнуты. Убраны неработавшие пункты («Инвертировать», «Чёрно-белая обработка», «Лёгкий режим»).

## Что нового в 5.1
- Приложение по умолчанию пустое (правила, команды, ответы, тексты автоответов). Готовый набор — Настройки → «Загрузить стандартный набор».
- Кнопки всплывающих окон репорта и слежки настраиваются: Команды → «Кнопки окон». Кнопка = название + цепочка действий (`@ans:sp`, `/sp {id}`, `/flip {id}`, `@help`, `@spoff` …).
- Из окна слежки можно отвечать автору репорта быстрыми ответами, не открывая клавиатуру.
- Резервная копия одним файлом (с журналом): сохранить / загрузить, автокопия раз в N часов в выбранную папку.
- Темы оформления (красная, сиреневая и др.).
- Формы из админ-чата, на которые не хватает уровня, больше не показываются.
- Журнал: у репортов и наказаний нет «минуса», убран комментарий ФВ внизу.
- Чат: копирование ника / ID / строки; очистка от времени и интерфейса игры при распознавании.
